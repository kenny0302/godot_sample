# 3D 迷宫游戏

一个使用 Godot 4.x 开发的 3D 第一人称迷宫游戏，支持桌面平台和 HTML5 网页运行。

## 游戏特性

- **3D 迷宫探索**: 随机生成的迷宫，每次游玩都不同
- **第一人称视角**: 使用 WASD 键移动，鼠标控制视角
- **智能小地图**: 按 M 键开关小地图，显示已探索区域
- **路径追踪**: 自动记录你走过的路径，在小地图上显示
- **胜利条件**: 找到绿色发光的出口即可获胜
- **跨平台支持**: 可在桌面和网页浏览器中运行

## 操作说明

### 桌面版
- **W/A/S/D**: 前进/左移/后退/右移
- **鼠标**: 控制视角
- **M 键**: 打开全屏小地图
- **Q 键**: 关闭小地图
- **ESC 键**: 释放/捕获鼠标（在游戏中），或退出游戏（胜利后）

### 网页版 (HTML5)
- **点击屏幕**: 开始游戏并锁定鼠标
- **W/A/S/D**: 前进/左移/后退/右移
- **鼠标**: 控制视角
- **M 键**: 打开全屏小地图
- **Q 键**: 关闭小地图
- **ESC 键**: 释放鼠标

## 小地图图例

- **黑色**: 墙壁
- **白色**: 已探索的路径
- **深灰色**: 未探索的路径
- **绿色方块**: 起点
- **红色方块**: 出口
- **黄色方块**: 当前位置

## 技术特点

- 使用递归回溯算法生成迷宫
- 动态路径追踪系统
- 实时更新的小地图
- 第一人称控制器
- 碰撞检测系统

## 如何运行

### 桌面版运行
1. 安装 Godot 4.2 或更高版本
2. 使用 Godot 打开项目文件夹
3. 按 F5 运行游戏

### HTML5 版本导出
1. 在 Godot 编辑器中打开项目
2. 点击菜单 **项目 → 导出**
3. 选择 "Web" 预设（已配置好）
4. 点击 "导出项目"
5. 选择输出路径（建议：`./build/web/index.html`）
6. 使用本地服务器运行导出的文件：
   ```bash
   # 方法1: 使用 Python
   cd build/web
   python -m http.server 8000

   # 方法2: 使用 Node.js
   cd build/web
   npx http-server
   ```
7. 在浏览器中访问 `http://localhost:8000`

### HTML5 版本注意事项
- 首次加载可能需要一些时间下载资源
- 需要点击屏幕才能锁定鼠标并开始游戏
- 建议使用 Chrome、Firefox 或 Edge 等现代浏览器
- 确保浏览器允许 WebGL 和指针锁定功能

## 技术优化 (HTML5)

项目已针对 HTML5 运行进行以下优化：
- 使用 `gl_compatibility` 渲染器以确保 WebGL 兼容性
- 实现了 Web 平台特定的鼠标捕获逻辑
- 添加了用户友好的点击开始提示界面
- 配置了完整的 Web 导出预设
