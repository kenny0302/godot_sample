# 3D 迷宫游戏

一个使用 Godot 4.x 开发的 3D 第一人称迷宫游戏。

## 游戏特性

- **3D 迷宫探索**: 随机生成的迷宫，每次游玩都不同
- **第一人称视角**: 使用 WASD 键移动，鼠标控制视角
- **智能小地图**: 按 M 键开关小地图，显示已探索区域
- **路径追踪**: 自动记录你走过的路径，在小地图上显示
- **胜利条件**: 找到绿色发光的出口即可获胜

## 操作说明

- **W/A/S/D**: 前进/左移/后退/右移
- **鼠标**: 控制视角
- **M 键**: 开关小地图
- **ESC 键**: 释放/捕获鼠标（在游戏中），或退出游戏（胜利后）

## 小地图图例

- **绿色方块**: 起点
- **红色方块**: 出口
- **黄色方块**: 当前位置
- **浅蓝色区域**: 已探索的路径
- **深灰色区域**: 未探索区域
- **白色线条**: 墙壁

## 技术特点

- 使用递归回溯算法生成迷宫
- 动态路径追踪系统
- 实时更新的小地图
- 第一人称控制器
- 碰撞检测系统

## 如何运行

1. 安装 Godot 4.2 或更高版本
2. 使用 Godot 打开项目文件夹
3. 按 F5 运行游戏
